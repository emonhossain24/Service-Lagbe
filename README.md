# Service Lagbe

Service Lagbe is a PHP and MySQL home-service booking system for customers and technicians. Customers browse categories, view service details and submit bookings. Technicians review assigned work and respond to service requests.

## Technology

PHP · MySQL/MariaDB · HTML · CSS · JavaScript · XAMPP.
