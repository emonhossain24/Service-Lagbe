# Service Lagbe

## Service Lagbe

Service Lagbe is a PHP and MySQL home-service booking system built around customer, technician and administrator workflows. Customers browse categories, view service details and submit bookings. Technicians review assigned work and respond to service requests.

### Administration

The `admin/` directory contains the administrator dashboard and pages for users, services, bookings, provider assignment, reviews and the homepage hero image. The dashboard also provides access to contact messages. Administrative pages check for an authenticated administrator session. See [the original project handbook](README.MD) for the complete booking flow and XAMPP setup.

### Technology

PHP · MySQL/MariaDB · HTML · CSS · JavaScript · XAMPP.
